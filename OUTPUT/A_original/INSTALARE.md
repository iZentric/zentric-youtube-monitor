# iZentric — instalare în VTube Studio

Pachetul a fost verificat cu **Cubism Core oficial (SDK 5-r.5)**: fișierul `.moc3`
se încarcă fără eroare (`vtuber/check_moc3.py` → `"ok": true`).

1. Șterge vechiul folder `...\VTube Studio_Data\StreamingAssets\Live2DModels\iZentric\`.
2. Dezarhivează arhiva aici, ca să rezulte `Live2DModels\iZentric\izentric.model3.json`.
3. VTS → *Change model* → **iZentric**.
