# iZentric — instalare în VTube Studio

1. Șterge vechiul `...\VTube Studio_Data\StreamingAssets\Live2DModels\iZentric\`.
2. Dezarhivează arhiva acolo → `Live2DModels\iZentric\izentric.model3.json`.
3. VTS → *Change model* → **iZentric**.

Pentru voce (lip sync): VTS → Settings → **Microphone** pornit, apoi în setările
modelului **Lip Sync** activat. Modelul are deja legătura `MouthOpen → ParamMouthOpenY`.
